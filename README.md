---

## 📌 Descrição

O **RH FitHub** é uma aplicação Front-end desenvolvida para auxiliar no gerenciamento de colaboradores de uma empresa do segmento fitness.

A aplicação permite visualizar e gerenciar informações dos colaboradores de forma prática e intuitiva, oferecendo uma interface para interação com a **API REST do RH FitHub**.

O projeto foi desenvolvido utilizando **React, TypeScript e Vite**, seguindo uma estrutura moderna e componentizada para aplicações web.

---

## 🖥️ Sobre o projeto

O Front-end do RH FitHub é responsável pela interface de interação entre o usuário e a API Back-end.

A aplicação permite realizar operações de gerenciamento de colaboradores, como:

* 👤 Cadastro de colaboradores;
* 🔎 Consulta de colaboradores;
* 🔍 Busca de colaboradores por ID;
* ✏️ Atualização de informações;
* 🗑️ Exclusão de colaboradores;
* 📋 Visualização dos dados cadastrados;
* 🔗 Comunicação com a API REST do RH FitHub.

---

## ⚙️ Principais funcionalidades

### 👥 Gerenciamento de colaboradores

A aplicação oferece uma interface para realizar as principais operações de **CRUD**:

| Operação   | Descrição                              |
| ---------- | -------------------------------------- |
| **Create** | Cadastro de novos colaboradores        |
| **Read**   | Consulta dos colaboradores cadastrados |
| **Update** | Atualização das informações            |
| **Delete** | Exclusão de colaboradores              |

---

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Grupo-05-Turma-Java-85/rh-frontend.git
```

### 2. Acesse a pasta do projeto

```bash
cd rh-frontend
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Após iniciar o projeto, o Vite exibirá no terminal o endereço local para acessar a aplicação, normalmente:

```text
http://localhost:5173
```

---

## 🏗️ Build para produção

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a versão de produção localmente:

```bash
npm run preview
```
